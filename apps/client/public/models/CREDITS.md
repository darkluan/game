# Model credits

Every model in this folder is released under Creative Commons Zero (CC0 1.0): free for personal,
educational and commercial use, credit not required. They are credited here all the same.

| Files                                      | Author                             | Pack                                 | Source                                                 |
| ------------------------------------------ | ---------------------------------- | ------------------------------------ | ------------------------------------------------------ |
| `skeleton_minion.glb`, `skeleton_mage.glb` | Kay Lousberg (www.kaylousberg.com) | KayKit Character Pack: Skeletons 1.0 | https://kaylousberg.itch.io/kaykit-skeletons           |
| `human_*.glb`                              | Quaternius (www.quaternius.com)    | RPG Characters (Nov 2020)            | https://opengameart.org/content/lowpoly-rpg-characters |

The files were reduced from the originals. The skeletons keep only the animations the game plays
(the originals carry 76 to 95 clips each). The RPG characters were converted from FBX, keep seven
animations each, share vertices where the originals repeated them, and carry their textures at half
size as JPEG.

Everything else in the game (the other twelve heroes, wild creatures, buildings, scenery) has no model file: it is built in code.
