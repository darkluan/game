The KayKit character files were reduced from the originals: only the animations the game plays were kept
(the originals carry 76 to 95 clips each). Geometry, rig and textures are unchanged.

The heroes have no model files: all sixteen are built in code (`src/scene/Swordsman.ts`, `Hydra.ts`,
`LongDragon.ts`, `Mech.ts`).
